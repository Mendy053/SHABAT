# SHABAT - מערכת תכנון ארוחות שבת

מערכת קלילה ומעוצבת אינטראקטיבית לתכנון ארוחה אחת קבועה. המערכת מאפשרת לכל משתמש להגדיר מה הוא מכין לאותה ארוחה, עם עיצוב מותאם לסמארטפון ותמיכה ב-ngrok לחשיפה לאינטרנט.

## ⚡ הפעלה מהירה

```bash
# 1. התקנת תלויות
cd server && npm install
cd ../client && npm install

# 2. הפעלת השרת עם ngrok
cd ../server && npm run dev:ngrok

# 3. הפעלת הקליינט (בטרמינל נפרד)
cd ../client && npm start
```

המערכת תהיה זמינה ב:
- **לוקלי**: `http://localhost:3000`
- **אינטרנט**: URL יוצג בטרמינל (למשל: `https://abc123.ngrok.io`)

## 🌐 הגדרת ngrok

### אוטומטי (מומלץ)
המערכת מפעילה ngrok אוטומטית עם הסקריפט `start-with-ngrok.js`:
```bash
npm run dev:ngrok
```

### הגדרת הקליינט
הקליינט יזהה אוטומטית את ה-URL של ngrok וישתמש בו. אם תרצה להגדיר ידנית:

1. **יצירת קובץ .env בקליינט**:
```bash
cd client
echo "REACT_APP_NGROK_URL=https://your-ngrok-url.ngrok.io" > .env
```

2. **או הגדרה דינמית**:
המערכת תשמור את ה-URL ב-localStorage ותשתמש בו אוטומטית.

### ידני
אם תרצה להפעיל ngrok בנפרד:
```bash
# התקנת ngrok
npm install -g ngrok

# הפעלת ngrok
ngrok http 3001
```

### קובץ .env
המערכת יוצרת/מעדכנת אוטומטית את קובץ `.env` עם ה-URL של ngrok:
```
PORT=3001
DB_PATH=./shabat.db
NGROK_URL=https://abc123.ngrok.io
NGROK_AUTH_TOKEN=your_auth_token_here
```

## 📱 שימוש במערכת

### כניסה למערכת
1. בחר משתמש מתוך הרשימה או הוסף משתמש חדש
2. כל משתמש מקבל צבע ייחודי לזיהוי

### הגדרת ארוחה
1. **הראשון שנכנס** יראה כפתור "הגדר שם"
2. הוא מגדיר את שם הארוחה (למשל: "ארוחת שבת")
3. השם נשמר ונציג לכל המשתמשים הבאים

### הוספת פריטים
1. לחץ על "הוסף פריט"
2. מלא את פרטי הפריט שאתה מכין
3. הפריט יופיע ברשימה הכללית

### עריכה ומחיקה
- **עריכה**: לחץ על כפתור העיפרון (ירוק)
- **מחיקה**: לחץ על כפתור הפח (אדום)
- כל המשתמשים יכולים לערוך ולמחוק כל פריט
