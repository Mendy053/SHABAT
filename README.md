# SHABAT - מערכת תכנון ארוחות שבת

מערכת קלילה ומעוצבת אינטראקטיבית לתכנון ארוחות שבת משפחתיות. המערכת מאפשרת לכל משתמש להגדיר מה הוא מכין לשבת, עם אזהרות על כפילויות ועיצוב מותאם לסמארטפון.

## 🌟 תכונות עיקריות

- **בחירת משתמש**: כניסה למערכת דרך בחירת משתמש מתוך רשימה
- **צבעים ייחודיים**: כל משתמש מקבל צבע ייחודי לזיהוי
- **שני טאבים**: 
  - "מה שאני מכין" - ארוחות אישיות
  - "מה שכולם מכינים" - סקירה כללית
- **אזהרות כפילות**: התראה כאשר מישהו אחר כבר לקח על עצמו ארוחה מסוימת
- **עיצוב מותאם**: תמיכה מלאה בסמארטפונים ועיצוב RTL לעברית
- **ממשק משפחתי**: עיצוב חם ומזמין המתאים לאווירת שבת

## 🛠️ טכנולוגיות

### Frontend
- **React 18** - ספריית UI
- **Framer Motion** - אנימציות חלקות
- **React Icons** - אייקונים
- **Axios** - בקשות HTTP
- **CSS3** - עיצוב מותאם אישית

### Backend
- **Node.js** - סביבת ריצה
- **Express.js** - מסגרת שרת
- **SQLite3** - מסד נתונים קל
- **CORS** - תמיכה בבקשות צד-לקוח
- **UUID** - יצירת מזהים ייחודיים

## 📦 התקנה והפעלה

### דרישות מקדימות
- Node.js (גרסה 14 ומעלה)
- npm או yarn

### התקנת הפרויקט

1. **שכפול הפרויקט**
```bash
git clone <repository-url>
cd shabat
```

2. **התקנת תלויות Backend**
```bash
cd server
npm install
```

3. **התקנת תלויות Frontend**
```bash
cd ../client
npm install
```

4. **הפעלת השרת**
```bash
cd ../server
npm run dev
```
השרת יפעל על `http://localhost:3001`

5. **הפעלת הקליינט**
```bash
cd ../client
npm start
```
האפליקציה תיפתח על `http://localhost:3000`

## 🔧 הגדרת ngrok (אופציונלי)

לחשיפת השרת לאינטרנט:

1. **התקנת ngrok**
```bash
npm install -g ngrok
```

2. **הפעלת ngrok**
```bash
ngrok http 3001
```

3. **עדכון קובץ config.env**
```
NGROK_URL=<your-ngrok-url>
```

## 📱 שימוש במערכת

### כניסה למערכת
1. בחר משתמש מתוך הרשימה או הוסף משתמש חדש
2. כל משתמש מקבל צבע ייחודי לזיהוי

### הוספת ארוחות
1. עבור לטאב "מה שאני מכין"
2. לחץ על "הוסף ארוחה"
3. מלא את פרטי הארוחה
4. המערכת תציג אזהרה אם הארוחה כבר קיימת

### ניהול ארוחות
- **צפייה**: כל הארוחות מוצגות עם שם המכין ותאריך
- **מחיקה**: רק המכין יכול למחוק את הארוחות שלו
- **אזהרות**: התראה על ארוחות שכבר נלקחו על ידי אחרים

## 🎨 עיצוב

המערכת כוללת:
- **עיצוב RTL** מלא לעברית
- **תמיכה במובייל** - מותאם לכל גדלי מסך
- **אנימציות חלקות** עם Framer Motion
- **צבעים חמים** המתאימים לאווירת שבת
- **ממשק משפחתי** ונגיש

## 📊 מבנה מסד הנתונים

### טבלת משתמשים (users)
- `id` - מזהה ייחודי
- `name` - שם המשתמש
- `color` - צבע ייחודי
- `created_at` - תאריך יצירה

### טבלת ארוחות (meal_items)
- `id` - מזהה ייחודי
- `name` - שם הארוחה
- `description` - תיאור (אופציונלי)
- `user_id` - מזהה המכין
- `created_at` - תאריך יצירה

## 🔒 אבטחה

- **CORS** מוגדר לבקשות מקומיות
- **SQL Injection** מוגן על ידי prepared statements
- **Validation** בצד שרת וקליינט
- **Error Handling** מקיף
